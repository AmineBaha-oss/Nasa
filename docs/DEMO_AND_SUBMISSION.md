# Demo and submission checklist

## 30-second video concept (must fit time)
- 0–5s: Show challenge problem: a sunlit site does not imply a particular spacecraft can operate.
- 5–11s: Select real site/date; show local horizon with Sun and Earth.
- 11–20s: Rotate body heading; live solar and antenna pass/fail visibly change.
- 20–26s: Compare another date or site; show different usable heading range, if the data support it.
- 26–30s: LANDERPRINT one-sentence message and limitations/provenance cue.

Do not fake actual constraints or claim certified landing safety. If no demonstrated multi-system tradeoff exists, show the narrower verified solar heading-date result and a separate antenna geometry screen.

## Required public submission items (check 2026 Guide)
- [ ] Final project public URL, GitHub URL, demo URL all work without login.
- [ ] English project title, concise summary, detailed description, implementation/evidence explanation.
- [ ] Challenge-specific NASA data source confirmed in Resources tab and cited.
- [ ] List additional NASA data, papers, packages, external source code and images.
- [ ] All AI tools actually used are disclosed; mention whether they assisted design, code, testing or documentation.
- [ ] Make license and source ledger public, with Apache NOTICE and MIT notices as applicable.
- [ ] Include limitations: local vs far-field, fictitious spacecraft specs, pointing vs radio link, 5-m DEM vs rock-scale safety, thermal unmodeled.
- [ ] No NASA endorsement/branding misuse.
- [ ] Record a 7-slide alternative only if time allows; choose one primary demo artifact.
- [ ] Official time: closes 2026-11-15 23:59 local time. Submit earlier.
