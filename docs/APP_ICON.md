# App icon

Original LANDERPRINT artwork generated with OpenAI's built-in image-generation tool on 2026-11-15. It depicts a lunar lander, horizon arc and orange heading pointer. It does not use a NASA logo or an external stock asset.

The original artwork is `web/public/icons/landerprint.png`. Browser and home-screen PNG exports (32, 180, 192 and 512 pixels) were resized using macOS `sips`. `web/index.html` links the favicon, Apple touch icon and `web/public/site.webmanifest`. The manifest supplies app identity and icons; it does not add offline support.
